ITE351 – AI & Applications

Comparative Study of Machine Learning Models for Sentiment Classification of Movie Reviews

Welcome to our ITE351 group project blog!

Project Overview

This project investigates the application of machine learning techniques to classify movie reviews as positive or negative.

We will use the IMDb movie review dataset and compare two machine learning algorithms:

* Multinomial Naive Bayes
* Logistic Regression

Our aim is to understand how these models process textual data and evaluate their effectiveness in sentiment classification.
